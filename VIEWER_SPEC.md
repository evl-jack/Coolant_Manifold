# Viewer implementation contract
Default comparison: original vs raw NS beta=8. Optional Stokes and smoothed selectors. Two modes: (1) true extruded planar FEM numerical geometry, (2) cylindrical engineering interpretation. The cylindrical interpretation does not preserve the planar asymmetry and is not a 3D CFD solution. Use explicit labels and do not color its surfaces as if they were calculated 3D flow fields. Default extruded mode is the faithful graded view. Use an explicit display-only thickness, not a physical depth conversion of per-unit-depth power.

## Exact field inputs
`evidence/verification/mesh-results/fitted-{original,raw,smoothed}-{0.25,0.125,0.0625}/fields.npz` and `evidence/nonlinear/fitted_stokes/fitted-stokes-{0.25,0.125,0.0625}/fields.npz`. Each fitted file stores `triangles` (N,3), `velocity_dofs` (N,6), `pressure_points_mm` (Np,2), `velocity_points_mm` (Nu,2), `pressure_pa` (Np,), `velocity_m_per_s` (Nu,2). Browser-friendly copies for the 0.25 mm fitted cases are supplied in `assets/fields/` as little-endian Float32/Uint32 binary arrays with JSON metadata; retain original NPZ for accurate data. These are display meshes, not the finest metrics meshes. Load coarse mesh first, optional finer files on demand. Report the field mesh resolution separately. Use true contour coordinates from the geometry files. Do not assume every NPZ has the same schema.

## FE interpolation
Use barycentric L1,L2,L3 for P1 pressure. For P2 velocity use L_i(2L_i−1) for vertices and 4L_iL_j for edge nodes. Determine actual local node order using the stored velocity node coordinates and triangle vertices/midpoints, or verify the solver's ordering. Interpolate velocity vector before taking norm. Use interpolation in shader or subdivide each parent element and compute nodal values from basis functions. Hover/click must report parent element id, x/y coordinates, actual interpolated pressure and velocity, units. No rainbow. Use shared scales and a zero-centered diverging scale for signed fields as appropriate; side flow is integral and has no local pass/fail velocity threshold. Mark port status in words/icons, not just colors.

## Cylindrical rendering
Main pipe radius 2 mm, axis x, center y=2,z=0; x 0..20. Side port radius 0.5 mm, vertical y axis at x=10,z=0, top y=7. Extract actual branch cross sections for y>4 from polygon; use half width r(y)=(x_R−x_L)/2, revolve around fixed side axis, enforce collar radius and document loss of asymmetry. At horizontal steps use one-sided sections (don't interpolate across discontinuities as though continuous). To connect with the curved pipe, extend the branch construction into the main cylinder and union/trim at its actual surface; do not leave a floating flange, internal overlapping faces, or seal flow openings. Any connecting extension is a visualization choice, not new design evidence. Show clear cutaway or openings and same camera/scale. Exact planar geometry must remain available as the main numerical view.

## Optimization animation
`evidence/verification/input/stage_01_beta_0`, `stage_02_beta_2`, `stage_03_beta_8` contain original and selected geometry/metrics/state/density checkpoints. Important: these stage `fields.npz` store a flat nondimensional state plus density arrays, NOT the fitted field schema. Use `input/mesh.npz` and source solver conventions to unpack and dimensionalize, or use the archived checkpoint geometry/density only with real stage metrics. Do not label fitted fields as stage states. Use real checkpoints with play/pause/reset; if morphing is purely visual label interpolation as such. Use progress.jsonl for actual evaluated objective and flow histories, not invented intermediate geometries.

## Interaction and acceptance
Linked cameras, zoom/orbit/pan, geometry mode, field mode, common scales, inspect elements, animation, metric panels per design with explicit constraint values/status, responsive phone layout, render within a few seconds. Load results.json. For immersed panels compare with immersed floor; for fitted panels show original physical side reference separately; never compare fitted flow to immersed threshold as though it were the same constraint. Keep the raw result primary. Use pinned dependencies and relative asset paths. Test on deployed URL. Missing assets must leave a transparent shell, not fake data.
