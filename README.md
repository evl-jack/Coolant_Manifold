# Project 4 — Coolant Manifold Optimization

**Live website:** [Coolant Manifold report and interactive viewer](https://evl-jack.github.io/Coolant_Manifold/)

This repository documents a planar, laminar-flow study of a coolant manifold junction. It includes the engineering report, interactive visualization, numerical evidence, verification records, source code, and archived solver outputs.

## Scope

The reported results describe a planar hydraulic model at one operating point. The study does not include heat-transfer analysis, physical testing, or a validated three-dimensional flow solution. The cylindrical viewer is a visualization of the planar results, not a three-dimensional CFD model. The numerical archive supports reconstruction of the site and report; a full end-to-end CFD rerun has not been established.

The published site is built from `index.md`, `index.html`, and the associated assets and data in this repository.
