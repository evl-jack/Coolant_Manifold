- [ ] Viewer 4: element-consistent state interpolation.
- [ ] Viewer 5: explanatory animation.
- [ ] Viewer 6: inspect element and values by hover/click.
- [ ] Viewer 7: both designs' objective/constraint values and pass/fail.
- [ ] Viewer 8: results.json-driven, phone width, quick rendering.
- [ ] One command regenerates results.json and numerical site content; document numerical rerun versus archive-only export honestly.
- [ ] Public solver and optimization code, pinned dependency versions, relative project paths, live equations checked, private browser test, repository/site URLs submitted on Canvas. Preserve graded commit.

Up to 15 bonus; N2 and topology potentially relevant but not automatically earned. Consult source for exact criteria and benchmark categories. Listed deadline Nov 25; do not assume extensions.
