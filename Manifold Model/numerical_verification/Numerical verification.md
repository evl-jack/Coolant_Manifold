# Numerical verification

The numerical results below use the supplied shared sheet and manufactured data. Benchmark pass/fail is reserved for the blind comparison.

## Solver and inputs

The new entry point is `Project 4/Manifold Model/numerical_verification/run.py`. Its `fem.py` assembles steady, incompressible, depth-averaged momentum and continuity on structured triangular P2/P1 meshes. It supports constant plate and Brinkman drag, prescribed volume forcing, periodic end identification, prescribed velocity on the remaining edges, a zero-mean pressure gauge, and Newton iteration with the assembled convection tangent. Strip sensitivities use the existing Manifold Model local coefficient and tangent helpers. The existing source and requirements files matched their pre-run SHA-256 hashes. The earlier benchmark outputs and hand reference were excluded.

- `fem.py` SHA-256 `25692d750ba0c225e3a4befb1015fbe2357fdd4d4a34e08fe69dbe48fab3c766`
- `run.py` SHA-256 `52836320be3b80598f0a6e0f5b55a99833d11780aae13f6cd50307893959bfc7`
- Runtime versions were Python 3.12.14, NumPy 2.5.4, and SciPy 1.18.1. The existing Project 4 virtual environment supplied the interpreter and packages. The verification entry point and Manifold Model sensitivity helpers supplied the project code.

All cases used ρ = 1000 kg/m³, μ = 0.001 Pa·s, and unmeshed depth b = 0.005 m unless that input is the one being perturbed. Plate drag was 12μ/b² = 480 Pa·s/m² at baseline. All solves used zero-mean pressure. The strip used L = 0.10 m, H = 0.020 m, uniform streamwise G = 1.0 N/m³, periodic ends, and no slip at y = 0 and H. Its Brinkman parameters were αₘₐₓ = 480 Pa·s/m² and qα = 2. The manufactured square had S = 0.10 m, V = 0.001 m/s, p★ = 0.001 Pa, and γ = 1. The runner uses the supplied f₂ and f₅ directly and imposes the supplied velocity traces. The exact fields enter only the error evaluation.

The shared sheet specified the mesh sequence for case 2. I selected the strip mesh with finer cross-stream spacing (H/96 ≈ 0.208 mm), used the middle case 2 mesh for the rotation pair, and used the same resolution for case 5. Mesh size hₘₐₓ is the longest element edge. Linear and Newton correction solves used scaled sparse direct factorization with no iterative tolerance. Reported linear backward errors are normwise in the infinity norm. The assembly used six Gauss points per direction on the Duffy map of each triangle. Error norms are absolute area integrals with eight points per direction and a Frobenius norm for the velocity gradient. Convergence rates divide the log error ratio by the log mesh size ratio between successive refinements.

The strip flow is Q = (b/L)∫uₓ dA. The peak is the maximum of the piecewise-quadratic axial field, evaluated at vertices and stationary points on edges and in interiors. Wall shear is the mean of |μ(∂ᵧuₓ + ∂ₓuᵧ)| on the two side walls. Wall force uses the signed streamwise traction from the same gradients. End fluxes use outward normals and P2 edge integration. Driving power is GLQ. Volume forces and powers use dV = b dA. Resisting forces and powers are negative. Dissipation is the positive sum of the viscous, plate, and Brinkman losses. The signed residuals sum the reported contributions. The force residual uses the wall stress reconstructed from the solved field.

Case 6 covers Q and driving power P = GLQ at fixed baseline driving force except when G itself is perturbed. Each physical input m is varied alone at m₀(1 ± ε). Length and width changes rescale node coordinates on the original connectivity. Changing depth affects both plate drag and the volume measure. Changing viscosity affects both viscous stress and plate drag. The derivatives below are with respect to physical m. For a derivative with respect to the dimensionless signed perturbation, multiply by m₀. T⁻ and T⁺ denote |J(m₀ ± m₀ε) − J(m₀) ∓ m₀ε J′(m₀)|. The centered differences use 72 independent sparse solves. Density is inactive in the linear strip. The flow derivative with respect to length is very small, so finite differences for that response are sensitive to subtractive cancellation. The optional fixed-flow variant was outside the selected checks.
