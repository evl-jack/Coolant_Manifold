# Project 4 fixed-pipe optimization

[GitHub Pages report](https://evl-jack.github.io/Coolant_Manifold/)

This directory contains the Markdown report, viewer source, selected numerical inputs and the pilot solver. Published files are in the repository’s `docs/` folder. Run these commands from `project4-fixed-pipe/` to regenerate the site from archived data.

```sh
python -m pip install -r manifold_dashboard/fixed_pipe_site/requirements-build.txt
python manifold_dashboard/fixed_pipe_site/build.py --output ../docs
```

See `manifold_dashboard/fixed_pipe_site/HANDOFF.md` for numerical evidence status and reproduction instructions.
